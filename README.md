# Aggregation Functions SQL

## Description

This Task contains SQL aggregation practice using the Northwind database in PostgreSQL.

## Objectives

- Practise SQL aggregate functions.
- Use GROUP BY to group records.
- Analyse customer, employee, product and order data.
- Complete 12 SQL queries and verify their results.

## Aggregate Functions Used

- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

## SQL Concepts Used

- GROUP BY
- HAVING
- ORDER BY
- JOIN
- CASE WHEN
- ROUND()
- Window Functions

## Tools Used

- PostgreSQL
- CodeCript SQL Playground
- Northwind Database

## Files Included

- Aggregation Function.SQL – Contains all 12 SQL queries.
- SQL Outputs.md – Contains the results displayed in tables.
